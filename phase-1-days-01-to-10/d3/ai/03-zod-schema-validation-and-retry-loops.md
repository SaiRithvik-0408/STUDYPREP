# Day 3: Self-Healing AI Pipelines & Automated Zod Retry Loops

When building mission-critical AI applications in production, an LLM will occasionally produce malformed JSON or miss a required schema key. A senior AI engineer does not let the application crash; they implement a **Self-Healing Schema Loop**.

---

## 1. The Self-Healing Architecture Pattern

```
User Input ──► [ LLM Generation ]
                      │
                      ▼
              [ Raw Output String ]
                      │
                      ▼
              [ Zod Schema Parse ]
                 │          │
        (Valid)  │          │ (Validation Error)
                 ▼          ▼
             [ Success ]   [ Build Feedback Prompt with Zod Error ]
                            │
                            ▼
                    [ Retry with Feedback (Max 3 Tries) ]
```

Instead of simply re-running the same prompt and hoping for a better result, we take **the exact compiler/validation error generated by Zod** and feed it back to the model as an error correction prompt!

---

## 2. Complete Production Implementation in TypeScript

```typescript
import { z, ZodError } from 'zod';

// Define the expected strict JSON structure
export const JobPostingSchema = z.object({
  jobTitle: z.string().min(3),
  department: z.string(),
  minimumYearsOfExperience: z.number().nonnegative(),
  requiredSkills: z.array(z.string()).min(1),
  isRemoteFriendly: z.boolean(),
  salaryRange: z.object({
    currency: z.string().default('USD'),
    minSalary: z.number().positive(),
    maxSalary: z.number().positive(),
  }),
});

export type JobPosting = z.infer<typeof JobPostingSchema>;

// Self-Healing Generator Function
export async function generateValidatedJobPosting(
  rawJobDescription: string,
  apiKey: string,
  maxRetries = 3
): Promise<JobPosting> {
  let feedbackMessage = '';

  for (let attempt = 1; attempt <= maxRetries; attempt++) {
    const prompt = `
You are an enterprise HR data extraction engine.
Extract the job posting details strictly according to this JSON schema:
${JSON.stringify(JobPostingSchema.description || {}, null, 2)}

Expected keys:
- jobTitle (string)
- department (string)
- minimumYearsOfExperience (number)
- requiredSkills (string array)
- isRemoteFriendly (boolean)
- salaryRange ({ currency: string, minSalary: number, maxSalary: number })

${feedbackMessage}

Job Description:
"""${rawJobDescription}"""

OUTPUT STRICTLY RFC-8259 JSON. NO PREAMBLE.
`;

    try {
      const response = await fetch(
        `https://generativelanguage.googleapis.com/v1beta/models/gemini-1.5-flash:generateContent?key=${apiKey}`,
        {
          method: 'POST',
          headers: { 'Content-Type': 'application/json' },
          body: JSON.stringify({
            contents: [{ role: 'user', parts: [{ text: prompt }] }],
            generationConfig: {
              temperature: 0.0, // Zero temperature for strict deterministic syntax
              responseMimeType: 'application/json',
            },
          }),
        }
      );

      const data = await response.json();
      const rawText = data.candidates?.[0]?.content?.parts?.[0]?.text;

      if (!rawText) throw new Error('Model produced an empty response.');

      // Step 1: JSON parse
      const parsedJson = JSON.parse(rawText);

      // Step 2: Zod Schema validation
      const validatedPosting = JobPostingSchema.parse(parsedJson);

      // If validation succeeds, return result immediately!
      return validatedPosting;
    } catch (err) {
      if (err instanceof ZodError) {
        console.warn(`[Attempt ${attempt}/${maxRetries}] Schema validation failed:`, err.format());
        // Construct targeted feedback for the next retry turn
        feedbackMessage = `
PREVIOUS ATTEMPT FAILED WITH VALIDATION ERRORS:
${JSON.stringify(err.issues, null, 2)}
Please fix these exact schema violations and output valid JSON.
`;
      } else {
        console.warn(`[Attempt ${attempt}/${maxRetries}] Parsing error:`, err);
        feedbackMessage = `Your previous output could not be parsed as valid JSON. Ensure strict JSON formatting.`;
      }

      if (attempt === maxRetries) {
        throw new Error(`Failed to generate valid JobPosting after ${maxRetries} attempts.`);
      }
    }
  }

  throw new Error('Unexpected loop termination');
}
```

## 3. Why Interviewers Love This Pattern
1. **Fault-Tolerant System Design**: It demonstrates that you treat AI outputs as untrusted third-party inputs.
2. **Defensive Programming**: By automating error recovery with feedback loops, you eliminate 99.9% of LLM JSON runtime parsing crashes in production.
