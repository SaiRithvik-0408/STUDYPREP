# Day 9: Modern AI & Streaming UI Architecture (Server-Sent Events & Vercel AI SDK)

If an LLM takes 6 seconds to generate a 400-word response, making a standard HTTP request forces the user to stare at a blank loading spinner for 6 full seconds. **Streaming UI** delivers tokens to the user's screen in real-time as they are generated by the GPU, dropping **Time to First Byte (TTFT)** from 6,000ms down to **~300ms**.

---

## 1. How Streaming Works: Server-Sent Events (SSE)

Unlike WebSockets (which are full-duplex and require TCP connection state), **Server-Sent Events (SSE)** run over standard HTTP with `Transfer-Encoding: chunked`:

```
Client ──(POST /api/chat)──► Server ──► LLM API (Stream)
                             │
Client ◄──(data: "Hello")─────┤ (Token 1: 200ms)
Client ◄──(data: " world")────┤ (Token 2: 240ms)
Client ◄──(data: "!")─────────┤ (Token 3: 280ms)
Client ◄──(data: [DONE])──────┘ (Connection closes)
```

### HTTP Headers for SSE:
```http
Content-Type: text/event-stream
Cache-Control: no-cache
Connection: keep-alive
```

## 2. Next.js 15 Streaming Route Handler (Vercel AI SDK)

```typescript
// app/api/chat/route.ts
import { GoogleGenerativeAI } from '@google/generative-ai';

const genAI = new GoogleGenerativeAI(process.env.GEMINI_API_KEY!);

export async function POST(req: Request) {
  const { messages } = await req.json();
  const lastMessage = messages[messages.length - 1].content;

  const model = genAI.getGenerativeModel({ model: 'gemini-1.5-flash' });

  // 1. Initiate real-time token stream from model
  const responseStream = await model.generateContentStream(lastMessage);

  // 2. Transform into a Web API ReadableStream
  const stream = new ReadableStream({
    async start(controller) {
      const encoder = new TextEncoder();
      for await (const chunk of responseStream.stream) {
        const text = chunk.text();
        controller.enqueue(encoder.encode(text));
      }
      controller.close();
    },
  });

  // 3. Stream raw text chunks directly to client
  return new Response(stream, {
    headers: {
      'Content-Type': 'text/plain; charset=utf-8',
      'Transfer-Encoding': 'chunked',
    },
  });
}
```

## 3. Frontend Streaming Component (`useChat`)

```tsx
// app/chat/page.tsx
'use client';

import { useChat } from 'ai/react';

export default function StreamingChatInterface() {
  const { messages, input, handleInputChange, handleSubmit, isLoading } = useChat({
    api: '/api/chat',
  });

  return (
    <div className="max-w-2xl mx-auto p-4 flex flex-col h-screen">
      <div className="flex-1 overflow-y-auto space-y-4 mb-4">
        {messages.map((m) => (
          <div
            key={m.id}
            className={`p-4 rounded-xl ${
              m.role === 'user' ? 'bg-blue-600 text-white ml-auto max-w-md' : 'bg-gray-100 text-gray-900 mr-auto max-w-md'
            }`}
          >
            <p className="font-semibold text-xs opacity-70 mb-1">
              {m.role === 'user' ? 'You' : 'AI Assistant'}
            </p>
            <p className="whitespace-pre-wrap">{m.content}</p>
          </div>
        ))}
        {isLoading && <p className="text-gray-400 text-sm italic">AI is typing...</p>}
      </div>

      <form onSubmit={handleSubmit} className="flex gap-2">
        <input
          value={input}
          onChange={handleInputChange}
          placeholder="Ask anything..."
          className="flex-1 border p-3 rounded-lg focus:outline-blue-600"
        />
        <button type="submit" disabled={isLoading} className="bg-blue-600 text-white px-6 py-3 rounded-lg">
          Send
        </button>
      </form>
    </div>
  );
}
```
