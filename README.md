## 🚀 Interactive Web Portal & Quiz App

You can run the full curriculum and quiz engine as an interactive web portal right in your browser!

### How to Launch:
1. **Option A (One-Click Launch)**: Double-click **`start-app.bat`** in this folder. It automatically boots the server and opens `http://localhost:5000` in your default browser.
2. **Option B (Terminal Command)**: Open PowerShell or Command Prompt in this directory and run:
   ```bash
   node server.js
   ```
   Then open `http://localhost:5000` in any browser.

### Portal Features:
* 📅 **Day Selector**: Navigate effortlessly between Day 01 and Day 40 across all 4 phases.
* 🟢 **Status Tracking**: Mark any day as **Not Started (⚪)**, **In Progress (🟡)**, or **Completed (🟢)** with persistent `localStorage` auto-saving.
* ☑️ **Day Checklist**: Check off individual module tasks (DSA, Backend, Frontend, Docker, AI, Drills) as you study.
* 📖 **In-Portal Guide Reader**: Read all 280 manuscripts directly with syntax highlighting, tables, alerts, and one-click code copy buttons.
* 📝 **Personal Scratchpad**: Write and auto-save your own personal study notes and gotchas per day.
* 🎯 **Interactive Milestone Quizzes**: Take comprehensive tests for Phase 1, Phase 2, Phase 3, and Phase 4 with instant answer explanations, pillar scoring breakdowns, and celebration confetti.
* 📊 **Progress Dashboard**: View completion percentages, phase progress cards, quiz score history, and export/import JSON progress backups.
